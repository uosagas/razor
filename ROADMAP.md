# Roadmap

## Done

| Phase | Milestone | Status |
|---|---|---|
| 0 | Protocol contract + headless harness (`Razor.Cli`) | done |
| 1 | Client-side plugin ABI: handshake, capabilities, packet mirror, data service | done |
| 2 | Razor core port: world model, agents, macros, profile/`.macro` compatibility | done |
| 3 | Avalonia UI shell (classic Razor tab layout) | done |
| 4 | Razor scripting + Lua engine with professional IDE editor (highlighting, autocomplete, console, breakpoints) | done |
| 5 | VScript node editor (blueprint-style, file-compatible with the in-client editor) | done |
| 6 | Deployment: signed releases distributed through the UOSagas launcher | done |

## Planned / ideas

- Remaining Razor CE parity items (ShowPartyStats, some object-property text flags)
- More Lua API surface as shard features grow
- Localization of the UI
- Linux/macOS release channels (the code is cross-platform; packaging and testing are not automated yet)

Suggestions welcome — please open an issue or see [CONTRIBUTING](CONTRIBUTING.md).
